usage: chronodownloader drop --output DIR
                             (--entry-ids LIST | --only LIST | --all) [options]

Delete the selected works from the store of an output root and clear their pages sampled by
inspect, so the next run processes them from scratch.

options:
  -h, --help        show this help message and exit

works to drop (exactly one):
  --entry-ids LIST  drop these works
  --only LIST       drop the works in these stored statuses; from complete, partial, failed,
                    no_match, needs_review, deferred, blocked
  --all             drop every work of the store

output:
  --output DIR      output root

run control:
  --dry-run         list what would be dropped
  --json            print one JSON summary line on stdout

Exit codes:
  0    every selected work was dropped, or in a dry run would be
  1    a work was refused: another run holds it
  2    usage error: no store in the output root, a store the tool refuses,
       or not exactly one of --entry-ids, --only and --all
  130  interrupted (Ctrl+C or Ctrl+Break)

With --json, stdout carries exactly one JSON summary line on every exit; progress, warnings and
errors go to stderr.

Examples:
  List what dropping the failed works would delete:
    chronodownloader drop --output out --only failed --dry-run
